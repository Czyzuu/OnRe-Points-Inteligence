METHODOLOGY

How the model works

  1. Wallets are matched by address across snapshots.
  2. Consecutive snapshot dates represent one daily points-credit cycle.
  3. Existing wallets use wallet-level or cohort-level stationary velocity.
  4. The simulated wallet earns points from editable strategy assumptions.
  5. Every wallet is re-ranked throughout the selected period.
  6. The gap between static and moving ranks represents leaderboard decay.

The initial model uses only two daily credit observations. It is useful for exploration, but several weeks of snapshots are needed for a stable long-term velocity estimate.
